# Кодын нүүдэл

Хүүхдүүд Python код бичиж даалгавар биелүүлдэг монгол хэлтэй компьютерийн веб тоглоом. Python код хөтөч дотор ажиллана. Сурагч хэрэглэгчийн нэр, нууц үгээр бүртгүүлээд өөр компьютерээс ахицаа үргэлжлүүлнэ.

## Vercel, Supabase дээр ажиллуулах

1. Supabase төсөл үүсгээд SQL Editor-д `supabase/migrations` хавтас дахь SQL файлуудыг нэрийн дарааллаар ажиллуулна.
2. Supabase Auth-ийн **Hooks → Before User Created** хэсэгт `public.pq_before_user_created` функцийг сонгож идэвхжүүлнэ. Email/password үйлчилгээ болон шинэ хэрэглэгчийн бүртгэлийг идэвхжүүлж, **Confirm email** тохиргоог унтраана. Тоглоом хэрэглэгчийн нэрийг Supabase-д таних дотоод хаяг болгон хувиргана. Сурагч хувийн имэйл оруулах шаардлагагүй. Эдгээр тохиргоог `supabase/config.toml` файлд мөн заасан.
3. Vercel-д энэ репозиторыг импортлоод `SUPABASE_URL`, `SUPABASE_PUBLISHABLE_KEY` гэсэн хоёр хувьсагчид төслийн API хаяг болон браузерт зориулсан нийтийн түлхүүрийг оруулна. `vercel.json` нь бүтээх команд, нийтлэх хавтсыг тохируулна.
4. Нэг компьютер дээр хэрэглэгчийн нэр, нууц үгээр бүртгүүлж, даалгавар гүйцэтгэнэ. Дараа нь өөр компьютер дээр ижил бүртгэлээр нэвтэрч ахицаа шалгана.

## Компьютер дээр ажиллуулах

Node.js 22 буюу түүнээс шинэ хувилбар ашиглана. Дээрх хоёр хувьсагчийг тохируулаад `npm ci`, дараа нь `npm run build` ажиллуулна. `python -m http.server 8000 --directory dist/vercel` командаар нээгээд хөтөчдөө `http://localhost:8000` гэж бичнэ. Хичээл болон тоглоомын шалгалтуудыг `npm test` командаар ажиллуулна.

Офлайнаар тоглохдоо `dist/client/python-quest-classroom.zip` багцыг задлаад `index.html` файлыг нээнэ. Офлайн ахиц тухайн хөтөч дээр хадгалагдана.
